# FAQ

### Liste de caméras vide

Mauvaise région. « Europe de l’Ouest » dans l’appli allemande = **EU**, pas WE.

### Le QR n’avance pas

Laissez la fenêtre ouverte et confirmez dans le téléphone.

### VLC est noir

VLC 3 échoue souvent sur HEVC/RTSP. Ce n’est pas un flux mort. Utilisez Agent DVR / Frigate.

### J’attendais 60 im/s

Beaucoup de modèles sortent ~**10 im/s** en HD. Le pont n’invente pas d’images.

### C’est de l’ONVIF ?

Non. RTSP seulement.

### La vidéo quitte-t-elle la maison ?

La signalisation va chez Tuya. En local, le média est en général caméra → ce PC. Un téléphone en 4G est un *second* spectateur (cloud).

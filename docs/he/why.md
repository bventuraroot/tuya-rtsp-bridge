# למה זה קיים

מצלמות Tuya זולות בלי ONVIF/RTSP מקורי. **Tuya RTSP Bridge** הופך אותן ל-RTSP מקומי אחרי QR אחד:

```
rtsp://<מחשב-זה>:8554/<CameraName>/hd
```

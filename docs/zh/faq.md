# 常见问题

### 登录后摄像机列表是空的

区域不对。德语 App 里的「西欧」是 **EU**（`protect-eu`），不是 WE。

### 二维码一直不完成

保持窗口打开，在手机上确认。

### VLC 是黑的

VLC 3 播 HEVC/RTSP 经常失败。不代表流死了。请用 Agent DVR / Frigate。

### 我以为有 60 帧

很多型号高清大约 **10 帧**。网桥不会凭空造帧。

### 这是 ONVIF 吗？

不是。只有 RTSP。

### 视频会离开我家吗？

信令走涂鸦。本机观看时媒体一般是摄像机 → 这台电脑。手机用流量看是**第二个**观众（走云）。

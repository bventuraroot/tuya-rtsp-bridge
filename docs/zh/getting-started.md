# 入门

适用于出现在 **涂鸦智能**、**Smart Life** 或 **iSmartLife** 里的摄像机。

1. 安装 Python 3.10+（Windows 勾选 **Add to PATH**）。
2. 运行安装包或 `launch.bat` / `./launch.sh`。
3. 选择与手机 App 相同的区域。
4. 生成二维码 → 扫描 → **确认**。
5. 把高清地址复制到 NVR。

会话：`%APPDATA%\TuyaRtspBridge` 或 `~/.local/share/tuya-rtsp-bridge/`。

换 Wi‑Fi：**不要**从账号里删除摄像机。到新地点在 App 里改网络，启动网桥，NVR 里只改电脑 IP。

云台：按住箭头移动，松开停止。本地协议 TCP **6668**。

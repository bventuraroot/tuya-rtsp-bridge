# Porque isto existe

Câmaras Tuya baratas: sem ONVIF, sem RTSP nativo, app cloud.

**Tuya RTSP Bridge** → RTSP local após um QR:

```
rtsp://<este-pc>:8554/<CameraName>/hd
```

Sinalização Tuya; vídeo local costuma ser câmara → o seu PC na LAN. Engine MIT: [seydx/tuya-ipc-terminal](https://github.com/seydx/tuya-ipc-terminal).

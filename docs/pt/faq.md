# Perguntas frequentes

### A lista de câmeras está vazia

Região errada. «Europa Ocidental» no app alemão é **EU**, não WE.

### O QR não termina

Deixe a janela aberta e confirme no telefone.

### O VLC está preto

O VLC 3 costuma falhar com HEVC/RTSP. O fluxo não morreu. Use Agent DVR / Frigate.

### Eu esperava 60 fps

Muitos modelos saem a cerca de **10 fps** em HD. A ponte não inventa quadros.

### É ONVIF?

Não. Só RTSP.

### O vídeo sai de casa?

A sinalização vai para a Tuya. Em local o meio costuma ser câmera → este PC. Um celular em dados é um *segundo* espectador (nuvem).

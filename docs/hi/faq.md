# अक्सर पूछे जाने वाले प्रश्न

### लॉगिन के बाद कैमरा सूची खाली है

गलत क्षेत्र। जर्मन ऐप में «पश्चिमी यूरोप» = **EU**, WE नहीं।

### QR पूरा नहीं होता

खिड़की खुली रखें और फ़ोन पर पुष्टि करें।

### VLC काला है

VLC 3 HEVC/RTSP पर अक्सर असफल। स्ट्रीम मरी नहीं है। Agent DVR / Frigate चलाएँ।

### मुझे 60 fps चाहिए थे

कई मॉडल HD में लगभग **10 fps** देते हैं। ब्रिज फ़्रेम नहीं बनाता।

### क्या यह ONVIF है?

नहीं। केवल RTSP।

### क्या वीडियो घर से बाहर जाता है?

सिग्नलिंग टुया जाती है। यहाँ देखने पर माध्यम आमतौर पर कैमरा → यह पीसी है। मोबाइल डेटा वाला फ़ोन **दूसरा** दर्शक है (क्लाउड)।

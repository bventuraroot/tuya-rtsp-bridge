# Brand

Mark: a dome camera on the same CRT phosphor palette as the app (`#0c100c` / `#c8e6b8` / `#e2b13c`). No live video, no device IDs.

| File | Use |
|---|---|
| `docs/images/logo.svg` | Source mark |
| `docs/images/logo.png` | README (512) |
| `docs/images/logo-mark.png` | Linux hicolor 256 |
| `docs/images/social.png` | GitHub / link preview 1280×640 |
| `docs/images/app.ico` | Windows Setup + shortcuts |
| `web/logo.svg`, `web/logo.png`, `web/favicon.ico` | Local UI |

Rebuild rasters:

```bat
python docs\scripts\make_brand.py
```

# 왜 필요한가

저가 Tuya 카메라: ONVIF/네이티브 RTSP 없음. **Tuya RTSP Bridge**는 QR 한 번으로 로컬 RTSP:

```
rtsp://<이-PC>:8554/<CameraName>/hd
```

Engine MIT: [seydx/tuya-ipc-terminal](https://github.com/seydx/tuya-ipc-terminal).

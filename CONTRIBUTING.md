# Contributing

1. Do **not** commit `%APPDATA%\TuyaRtspBridge`, cookies, `localKey`, device IDs, or LAN IPs.
2. English or German UI strings go in `src/i18n.py`.
3. The RTSP engine lives in `vendor/tuya-ipc-terminal` (upstream MIT, keep LICENSE).
4. Open a PR with a short description of the camera model you tested.

## Code of conduct

Be decent. No harassment. Security issues: open a private GitHub security advisory, do not file public exploit PoCs against Tuya cloud.
